# Second Brain CLI

A local command-line tool that ingests Markdown files, PDFs, plain text, web URLs (as bookmarks), and GitHub repositories. It chunks and embeds the contents of these sources using a local SentenceTransformers model, stores the vectors in ChromaDB, and answers questions over all ingested material with answers (and citations) generated by a local Ollama (llama3) LLM.

- **Ingestion:** Supported sources: `.md`, `.txt`, `.pdf`, web URLs (text-only), and GitHub repositories. Uses efficient chunking and smallest local transformer for embeddings.
- **Query:** Answers are contextually accurate and always cite sources.
- **Fully Local:** Zero external API calls — runs entirely offline if Ollama is local.

## Usage

```
python second_brain.py ingest <source>
python second_brain.py ask <question>
```

- Example: `python second_brain.py ingest mynotes.md`
- Example: `python second_brain.py ingest https://arxiv.org/pdf/2102.00000.pdf`
- Example: `python second_brain.py ask "What are the key findings in mynotes.md?"`

Requirements: Python 3.9+, Ollama running llama3 locally, all dependencies installed (see also: `PyPDF2`, `BeautifulSoup4`, `requests`, `gitpython`, `click`, `sentence-transformers`, `chromadb`).
