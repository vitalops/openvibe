# GitHub Analytics Dashboard

openvibe builds a live analytics dashboard for the `pallets/flask` GitHub
repository, then automatically evaluates its own output using the simulation harness.

---

## What Happens

**Phase 1 — Build**

openvibe reads the task description and creates:

```
app/fetch.py     ← fetches from GitHub API, stores in SQLite
app/server.py    ← Flask server with JSON endpoints + HTML UI
data/github.db   ← populated by fetch.py
SOLUTION.md      ← what was built, how to run it, any limitations
```

**Phase 2 — Evaluate**

The simulation harness takes over. It reads the task description and SOLUTION.md,
then automatically:

1. **Designs** a complete evaluation environment — personas, tools, evaluation
   criteria — suited to what was actually built. No manual setup required.
2. **Generates** a scenario dataset across difficulty levels.
3. **Runs** each scenario as a multi-turn simulation.
4. **Evaluates** and scores every scenario.
5. **Saves** a full report to `eval_output/`:
   - `github_dashboard.jsonl` — the scenario dataset
   - `github_dashboard_report.json` — raw metrics
   - `github_dashboard_report.md` — human-readable report with per-scenario breakdown

The evaluation environment is entirely auto-generated. TASK.md contains only
the task description — no evaluation criteria, no schema definitions.

---

## Running Via TUI

```bash
openvibe
```

Then type any of these — no slash command needed:

```
build and evaluate examples/github_dashboard/TASK.md
run examples/github_dashboard/TASK.md
execute the pipeline from examples/github_dashboard/TASK.md
```

---

## Running Via Python

```bash
# Full pipeline
python examples/github_dashboard/run.py

# Build only
python examples/github_dashboard/run.py --phase build

# Evaluate only (needs SOLUTION.md from a prior build)
python examples/github_dashboard/run.py --phase evaluate

# Different model
python examples/github_dashboard/run.py --model openai/gpt-4o
```

Set `GITHUB_TOKEN` to avoid the 60 req/hr unauthenticated rate limit:

```bash
export GITHUB_TOKEN=ghp_...
python examples/github_dashboard/run.py
```

---

## Output

After running, `eval_output/github_dashboard_report.md` contains:

- Summary metrics (mean score, pass rate, outcome accuracy)
- Scores by difficulty (easy / medium / hard / adversarial)
- Scores by criterion (auto-generated by the harness)
- Per-scenario results with feedback and improvement suggestions
